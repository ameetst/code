───────────────────────────────────────────────────────────────────────────
ENTRY FILTERS (AND LOGIC)
───────────────────────────────────────────────────────────────────────────

Filter 1: 52-Week High Proximity
  └─ (high - close) / high ≤ 0.25  [ETF within 75% of peak]

Filter 2: MOM_ACCEL > 0
  └─ 0.4*(Z_1m + Z_3m) - 0.2*Z_6m > 0  [Positive acceleration]

BOTH MUST PASS for allocation eligibility

───────────────────────────────────────────────────────────────────────────
RANKING (BY WEIGHTED SHARPE ONLY)
───────────────────────────────────────────────────────────────────────────

Weighted Sharpe = 0.5 * Z_6M_SHARPE + 0.5 * Z_3M_SHARPE

Note: Filters are used for SCREENING, not for RANKING

───────────────────────────────────────────────────────────────────────────
WEEKLY REBALANCE (MONDAY ONLY)
───────────────────────────────────────────────────────────────────────────

Entry: Top 5 ETFs (BULL) or Top 3 (PARTIAL) or 0 (BEAR)
       • Rank by Weighted Sharpe
       • Sector cap: 1 ETF per sector
       • Retain existing if rank ≤ 20

Exit:  • 5% TSL from running peak since entry
       • Rank outside top 20 (across investable universe)
       • Checked & executed Monday only (batch processing)

Timing: • Rebalance only on Mondays
        • Monday detection: pd.Timestamp(date).dayofweek == 0
        • Exit conditions checked & executed same day

───────────────────────────────────────────────────────────────────────────
REGIME FILTER (WEEKLY CADENCE)
───────────────────────────────────────────────────────────────────────────

Proxy: MONIFTY500 (Mirae Asset Nifty 500 ETF)
Fallbacks: BSE500IETF → HDFCBSE500 → NIFTYBEES

BULL:    EMA50 > EMA100 AND Price > EMA50    → 5 slots
PARTIAL: Price > EMA100 (but not BULL)       → 3 slots
BEAR:    Price ≤ EMA100                      → 0 slots (monitor only)

───────────────────────────────────────────────────────────────────────────
EXIT RULES (MONDAY-ONLY BATCH)
───────────────────────────────────────────────────────────────────────────

Rule 1: 5% Trailing Stop Loss (TSL)
  ├─ entry_price = Price at entry
  ├─ running_peak = Max NAV since entry (updated daily, checked Monday)
  ├─ TSL_trigger = running_peak * (1 - 0.05)
  └─ EXIT if current_close < TSL_trigger

Rule 2: Rank Outside Top 20
  └─ EXIT if RANK_FINAL > 20 (among investable ETFs)

Rule 3: Filters No Longer Pass
  └─ EXIT if (52h_high_fail OR MOM_ACCEL ≤ 0)

Timing: All checks & exits happen on Monday (batch processing)
